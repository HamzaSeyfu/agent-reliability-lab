The engineering point

    
The interesting failures are the ones where the aggregate score remains high. A conflicting payer policy or prompt-injection signal can coexist with otherwise excellent evidence. A score-only system can therefore look confident while making the wrong automation decision.

    
This public demo uses deterministic replay and synthetic inputs so every reviewer and CI run sees the same behavior without model keys or sensitive data.
